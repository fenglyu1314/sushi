## Purpose

提供决策阶段的白盒 UI：展示现金、食材库存与各配方可做份数，支持采购、即时生产与出餐台/货架间的拖放整理（上架/取消退料），并提供开摊入口进入模拟阶段。

## Requirements

### Requirement: 决策阶段状态展示

决策阶段 UI SHALL 展示当前现金、各食材库存与各配方当前可做份数，采用白盒占位（纯色块 + 文字标签），保证信息可读。

#### Scenario: 进入决策阶段刷新展示

- **WHEN** 进入某一天的决策阶段
- **THEN** UI 显示当前现金、每种食材的剩余库存、每个配方当前可做的最大份数

#### Scenario: 采购或生产后即时刷新

- **WHEN** 玩家完成一次采购或生产
- **THEN** 现金、相关食材库存与受影响配方的可做份数即时更新

### Requirement: 采购交互

决策阶段 UI SHALL 允许玩家为每种食材选择采购数量并提交采购，提交前展示单价与小计预览，提交后依据结果给出反馈。

#### Scenario: 采购成功

- **WHEN** 玩家选择某食材数量并点击采购、且现金充足
- **THEN** 现金扣减、库存增加，UI 反馈成功并刷新展示

#### Scenario: 现金不足采购失败

- **WHEN** 玩家提交的采购总价超过当前现金
- **THEN** 采购被拒绝、状态不变，UI 提示现金不足

### Requirement: 生产交互

决策阶段 UI SHALL 允许玩家对每个配方**即时生产**一份到出餐台（无耗时、无队列），展示单份成本预览与当前可做上限，并在出餐台已满或食材不足时禁用生产并提示。

#### Scenario: 即时生产一份

- **WHEN** 玩家点击某配方的「生产」且食材足够、出餐台未满
- **THEN** 立即扣料并产出一份成品落入出餐台，出餐台占用与可做上限即时更新

#### Scenario: 出餐台满禁用生产

- **WHEN** 出餐台已达容量上限
- **THEN** UI 禁用「生产」并提示「出餐台已满，请先上架或取消」

#### Scenario: 库存不足的提示

- **WHEN** 某配方当前可做份数为 0
- **THEN** UI 给出可做上限为 0 的提示并禁用该配方的「生产」

### Requirement: 出餐台与货架展示

决策阶段 UI SHALL 白盒展示出餐台（当前成品 / 容量）与货架 `N×N` 格（各格空 / 满一眼可辨）。

#### Scenario: 容器状态刷新

- **WHEN** 出餐台或货架的成品发生变化
- **THEN** UI 即时刷新出餐台占用数与各货架格的空 / 满状态

### Requirement: 拖放交互（上架 / 取消退料）

决策阶段 UI SHALL 支持将出餐台成品拖到货架空格（上架）或垃圾桶（**取消退料**：返还食材），并支持将货架成品拖到垃圾桶（取消退料）。非法放置 MUST 回弹且不改变状态，并给出白盒反馈。

#### Scenario: 拖放上架

- **WHEN** 玩家把出餐台一份成品拖到货架空格
- **THEN** 成品上架，出餐台与货架展示即时更新

#### Scenario: 拖到垃圾桶取消退料

- **WHEN** 备货阶段玩家把出餐台或货架成品拖到垃圾桶
- **THEN** 成品移除、食材原额返还，UI 提示「已退还食材」，不记录沉没成本

#### Scenario: 非法放置回弹

- **WHEN** 玩家把成品拖到非法目标（如已满货架、货架→出餐台）
- **THEN** 成品回弹到源位置，状态不变，UI 给出反馈

### Requirement: 开摊入口

决策阶段 UI SHALL 提供"开摊"入口，触发后进入模拟阶段。

#### Scenario: 点击开摊

- **WHEN** 玩家在决策阶段点击"开摊"
- **THEN** 游戏进入模拟阶段，决策面板隐藏、模拟面板显示

### Requirement: 决策阶段状态展示

决策阶段 UI SHALL 展示当前现金、各食材库存与各配方当前可做份数，采用白盒占位（纯色块 + 文字标签），保证信息可读。

#### Scenario: 进入决策阶段刷新展示

- **WHEN** 进入某一天的决策阶段
- **THEN** UI 显示当前现金、每种食材的剩余库存、每个配方当前可做的最大份数

#### Scenario: 采购或生产后即时刷新

- **WHEN** 玩家完成一次采购或生产
- **THEN** 现金、相关食材库存与受影响配方的可做份数即时更新

### Requirement: 采购交互

决策阶段 UI SHALL 允许玩家为每种食材选择采购数量并提交采购，提交前展示单价与小计预览，提交后依据结果给出反馈。

#### Scenario: 采购成功

- **WHEN** 玩家选择某食材数量并点击采购、且现金充足
- **THEN** 现金扣减、库存增加，UI 反馈成功并刷新展示

#### Scenario: 现金不足采购失败

- **WHEN** 玩家提交的采购总价超过当前现金
- **THEN** 采购被拒绝、状态不变，UI 提示现金不足

### Requirement: 生产交互

决策阶段 UI SHALL 允许玩家为每个配方选择生产份数并提交，展示单份成本预览与当前可做上限，提交后反馈实际生产份数。

#### Scenario: 生产受可做上限约束

- **WHEN** 玩家请求生产的份数超过当前库存/辅料所能支持的上限
- **THEN** 实际生产至上限份数，UI 反馈实际份数并刷新库存与成品展示

#### Scenario: 库存不足无法生产

- **WHEN** 某配方当前可做份数为 0
- **THEN** 该配方的生产按钮不可用或提交返回 0 份，UI 给出相应提示

### Requirement: 开摊入口

决策阶段 UI SHALL 提供"开摊"入口，触发后进入模拟阶段。

#### Scenario: 点击开摊

- **WHEN** 玩家在决策阶段点击"开摊"
- **THEN** 游戏进入模拟阶段，决策面板隐藏、模拟面板显示

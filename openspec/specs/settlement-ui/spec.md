### Requirement: 当日盈亏复盘展示

结算阶段 UI SHALL 呈现当日复盘：营收、采购成本、租金、浪费额与净利，并明确区分"流失（机会成本、不扣钱）"与"浪费/作废（沉没成本、实亏）"。

#### Scenario: 显示盈亏结构

- **WHEN** 进入结算阶段并收到复盘数据
- **THEN** UI 显示营收、采购成本、租金、浪费额、净利与结算后现金
- **AND** 盈利与亏损以不同颜色的白盒占位区分

#### Scenario: 区分流失与浪费

- **WHEN** 复盘数据同时包含流失与作废
- **THEN** UI 将流失作为机会成本单独呈现，不计入扣钱；将作废作为浪费额（实亏）呈现

### Requirement: 各款明细展示

结算阶段 UI SHALL 按寿司款式展示当日售出、作废与流失的数量明细，引导玩家复盘预测偏差。

#### Scenario: 展示各款明细

- **WHEN** 进入结算阶段
- **THEN** UI 逐款列出售出份数、作废份数与流失次数

### Requirement: 进入下一天入口

结算阶段 UI SHALL 提供"进入下一天"入口，触发后开始新一天并返回决策阶段展示。

#### Scenario: 点击进入下一天

- **WHEN** 玩家在结算面板点击"进入下一天"
- **THEN** 现金与结转库存保留、当日统计重置，游戏进入新一天的决策阶段，结算面板隐藏、决策面板显示

### Requirement: 复盘扩展位预留

结算阶段 UI SHALL 预留后续里程碑复盘内容（如"流言"）的展示位，本变更仅占位、不实现其数据。

#### Scenario: 展示占位区

- **WHEN** 进入结算阶段
- **THEN** UI 显示一个标注为后续内容的占位区，且不影响当前复盘数据的呈现

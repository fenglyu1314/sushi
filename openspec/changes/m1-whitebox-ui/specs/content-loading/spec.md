## ADDED Requirements

### Requirement: 从数据目录加载内容资源

系统 SHALL 从约定的数据目录加载 `.tres` 内容资源，构建运行时内容集（食材、配方、顾客类型、地点），使新增或调整内容无需修改脚本代码。

#### Scenario: 加载全部内容资源

- **WHEN** 游戏启动、内容加载器扫描约定数据目录
- **THEN** 目录下所有食材、配方、顾客类型、地点 `.tres` 均被加载为对应资源实例
- **AND** 食材可按 id 查询、配方以列表形式提供、地点可按 id 查询

#### Scenario: 配方内嵌引用自动带出依赖

- **WHEN** 加载一个引用了若干食材的配方资源
- **THEN** 该配方的每项 `RecipeIngredient` 正确指向对应食材资源
- **AND** 可据此计算单份成本与最大可做份数，无需额外手动拼接引用

#### Scenario: 内容目录为空或缺失

- **WHEN** 约定目录不存在或未包含任何内容资源
- **THEN** 加载器不崩溃，返回空内容集并发出警告
- **AND** 上层可据空内容集显示占位提示

### Requirement: 内容集只读查询接口

内容加载器 SHALL 向上层提供只读查询，用于按 id 取食材/地点、遍历配方列表，且不暴露可变内部结构导致内容被意外改写。

#### Scenario: 按 id 查询存在的食材

- **WHEN** 上层用一个已加载食材的 id 查询
- **THEN** 返回对应的食材资源

#### Scenario: 查询不存在的 id

- **WHEN** 上层用一个未加载的 id 查询食材或地点
- **THEN** 返回空（null）而非报错

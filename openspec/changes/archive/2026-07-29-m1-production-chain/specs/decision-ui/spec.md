## MODIFIED Requirements

### Requirement: 生产交互

决策阶段 UI SHALL 允许玩家对每个配方**即时生产**一份到出餐台（无耗时、无队列），展示单份成本预览与当前可做上限，并在出餐台已满或食材不足时禁用生产并提示。

#### Scenario: 即时生产一份

- **WHEN** 玩家点击某配方的「生产」且食材足够、出餐台未满
- **THEN** 立即扣料并产出一份成品落入出餐台，出餐台占用与可做上限即时更新

#### Scenario: 出餐台满禁用生产

- **WHEN** 出餐台已达容量上限
- **THEN** UI 禁用「生产」并提示「出餐台已满，请先上架或取消」

#### Scenario: 库存不足的提示

- **WHEN** 某配方当前可做份数为 0
- **THEN** UI 给出可做上限为 0 的提示并禁用该配方的「生产」

## ADDED Requirements

### Requirement: 出餐台与货架展示

决策阶段 UI SHALL 白盒展示出餐台（当前成品 / 容量）与货架 `N×N` 格（各格空 / 满一眼可辨）。

#### Scenario: 容器状态刷新

- **WHEN** 出餐台或货架的成品发生变化
- **THEN** UI 即时刷新出餐台占用数与各货架格的空 / 满状态

### Requirement: 拖放交互（上架 / 取消退料）

决策阶段 UI SHALL 支持将出餐台成品拖到货架空格（上架）或垃圾桶（**取消退料**：返还食材），并支持将货架成品拖到垃圾桶（取消退料）。非法放置 MUST 回弹且不改变状态，并给出白盒反馈。

#### Scenario: 拖放上架

- **WHEN** 玩家把出餐台一份成品拖到货架空格
- **THEN** 成品上架，出餐台与货架展示即时更新

#### Scenario: 拖到垃圾桶取消退料

- **WHEN** 备货阶段玩家把出餐台或货架成品拖到垃圾桶
- **THEN** 成品移除、食材原额返还，UI 提示「已退还食材」，不记录沉没成本

#### Scenario: 非法放置回弹

- **WHEN** 玩家把成品拖到非法目标（如已满货架、货架→出餐台）
- **THEN** 成品回弹到源位置，状态不变，UI 给出反馈

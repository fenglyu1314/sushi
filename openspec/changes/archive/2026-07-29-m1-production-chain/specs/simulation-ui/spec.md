## MODIFIED Requirements

### Requirement: 模拟阶段进度可视化

模拟阶段 UI SHALL 可视化当天售卖进度（当前 tick / 总 tick），并展示**货架各格状态与出餐台占用**（替代原「剩余成品份数」），采用白盒占位呈现。

#### Scenario: tick 推进更新进度

- **WHEN** 模拟阶段每推进一个 tick
- **THEN** UI 更新当前售卖进度，并刷新货架各格与出餐台的占用状态

## ADDED Requirements

### Requirement: 营业阶段制作队列持续运行

模拟阶段 UI SHALL 持续展示制作队列与当前制作进度条（营业中制作不中断），并在出餐台满导致暂停时给出提示。营业阶段 UI SHALL 允许玩家将配方**加入制作队列**（营业期唯一的生产方式），并反馈已入队份数。

#### Scenario: 营业中加入队列

- **WHEN** 营业阶段玩家点击某配方的「加入队列」
- **THEN** 该配方增加一份待制作项，队列展示与已入队计数即时更新

#### Scenario: 营业中制作推进

- **WHEN** 营业阶段进行中且制作队列有待制作项、出餐台未满
- **THEN** UI 显示当前制作款式的进度条随时间推进，完成后成品落出餐台并刷新展示

#### Scenario: 营业中暂停提示

- **WHEN** 营业阶段中出餐台已满导致制作暂停
- **THEN** UI 提示制作暂停，出现空位后自动恢复

### Requirement: 营业阶段拖放补货与作废

模拟阶段 UI SHALL 支持玩家在营业中把出餐台成品拖到货架空格（补货）或垃圾桶（作废），以及把货架成品拖到垃圾桶。营业阶段拖到垃圾桶 MUST 按作废处理（沉没成本），不返还食材。

#### Scenario: 卖空后补货

- **WHEN** 货架某格因成交变空，玩家把出餐台成品拖入该格
- **THEN** 该格补入成品，出餐台 -1，后续顾客可购买该款

#### Scenario: 营业中作废止损

- **WHEN** 玩家把出餐台或货架成品拖到垃圾桶
- **THEN** 该成品作废、记录沉没成本、不返还食材，对应容器展示即时更新

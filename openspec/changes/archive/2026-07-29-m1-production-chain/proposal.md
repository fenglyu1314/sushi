## Why

当前 M1 的生产是「决策阶段即时出成品 + 全屏文字面板」，缺失 GDD §5.4 设计的核心手感：营业时做寿司需要时间、做好先进**出餐台**、玩家手动摆上**货架**、卖空再补货。这条「现做 → 摆盘 → 补货」的临场经营正是摆摊玩法「好不好玩」的关键判断点，需要在白盒阶段先验证。本轮把生产链重做为「备货即时生产 + 营业单线程制作队列 + 出餐台 + 货架」，让玩家真正体验制作节奏与手动止损的压力。

本轮只做**核心生产链的功能白盒**（下方操作面板）；上方场景演出层、冰箱格子化各自另立 change。

## What Changes

- 生产模型按阶段拆分：**备货阶段瞬间生产**（点击即出成品、无耗时、可取消退料），**营业阶段改为单线程制作队列**（选配方入队、前一个做完自动做下一个、每款有制作耗时 `Recipe.craft_time`）。**BREAKING**（改变现有即时生产语义）
- 新增**出餐台**（原「缓冲区」，正式术语）：制作完成的成品先落出餐台；出餐台有容量上限（初始 4），**营业阶段满则暂停制作、出空位恢复**，**备货阶段满则拒绝生产**。容量升级仅留接口、本轮不实装。
- 新增**货架**（N×N 格，成品**每款占 1 格**）：玩家从出餐台**手动拖放**成品到货架格；货架满则无法再放。
- 新增**垃圾桶拖放，按阶段分流**：**营业阶段 = 作废**（沉没成本，见术语表「作废」）；**备货阶段 = 取消退料**（返还食材、不记沉没成本）。开摊 = 不可逆提交点。
- **sales 售卖来源改为「仅货架上的成品」**：营业中卖掉一格 → 空出 → 玩家从出餐台补货。**BREAKING**（原为从当日成品池直接扣）
- `Recipe` 数据模型新增 `craft_time`（制作时长，秒，仅营业阶段生效）字段。
- 决策 / 营业 UI 相应调整：备货 UI 为「即时生产 + 拖放上架 / 退料」，营业 UI 为「入队 + 进度条 + 拖放补货 / 作废」（仍为纯色块 + 文字白盒，场景演出层不在本轮）。
- 术语表新增「出餐台」词条。

**Non-goals（本轮不做）**
- 上方场景演出层（餐车 / 横版道路 / 顾客走动的纯表演）→ 另立 change。
- 冰箱格子化（主料占格）→ 另立 change，本轮沿用现有数值食材库存。
- 出餐台容量升级 UI（仅留接口）。
- 顾客排队 / 前排取货位 / 犹豫窗口。

## Capabilities

### New Capabilities
- `shelf-buffer`: 出餐台与货架两个成品容器的状态模型与规则——出餐台容量约束（营业满暂停 / 备货满拒绝）、货架 N×N 且成品每款占 1 格、成品在「出餐台→货架 / →垃圾桶」之间的合法转移，以及垃圾桶动作按阶段分流（营业作废沉没 / 备货退料返还）与结算剩余一律作废。

### Modified Capabilities
- `sushi-production`: 由「决策阶段即时生产」改为「备货即时生产 + 营业单线程制作队列（每款耗时、成品落出餐台、满暂停）」，并新增备货阶段取消退料。
- `sales`: 售卖来源由「当日成品池」改为「仅货架上的成品」。
- `game-data-model`: `Recipe` 新增 `craft_time`（制作时长，仅营业阶段生效）字段。
- `decision-ui`: 生产交互为「即时生产一份到出餐台」；新增出餐台 / 货架白盒展示、拖放交互（出餐台→货架上架 / →垃圾桶取消退料）。
- `simulation-ui`: 营业阶段生产交互为「加入制作队列」，持续运行队列与进度条；展示出餐台 / 货架状态；支持拖放补货与作废（沉没成本）。

## Impact

- **代码**：`game/scripts/data/recipe.gd`（+`craft_time`）、`game/scripts/systems/run_state.gd`（成品池拆为出餐台 / 货架、备货即时生产 + 营业制作队列、暴露纯逻辑 `advance_crafting(delta)`、取消退料 / 作废按阶段分流、结算清算、sales 取货源改动）、`game/scripts/core/day_cycle.gd`（营业阶段每帧驱动 `advance_crafting`，与 sales tick 同起同停）、`game/scripts/ui/decision_panel.gd` 及营业阶段面板（即时生产 / 入队 / 进度条 / 拖放）、事件总线（制作开始 / 完成、暂停 / 恢复、拖放 / 作废 / 退料信号）。
- **数据资源**：现有配方 `.tres` 需补 `craft_time`（在编辑器内操作，AI 不直接改 .tres）。
- **文档**：`docs/00-术语表.md` 新增「出餐台」词条；与 GDD §5.4 白盒实现对齐。
- **存档**：`run_state` 结构变化会影响 save-system 兼容性；M1 白盒阶段可接受存档重置。

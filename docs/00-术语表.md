- **引用约定**：本表定义中出现的 `§x.x` 指向 **GDD（`01-游戏设计文档-GDD.md`）** 的对应章节。
- **弃用叫法**：右列列出的词一律不再作为正式表述；仅在面向玩家的叙事文案中，可使用括注标明的「玩家向别名」。

## 术语定义

| 正式术语 | 定义 | 弃用叫法 |
|---------|------|---------|
| **好感度**（简称「好感」）| 衡量玩家经营水平的核心口碑指标，取值 `0~100%`。摆摊阶段**每个地点各自独立**持有一份好感度；开店后由各地点好感度**按比例合并**为单一的店铺好感度。由「顾客是否买到想要的商品」驱动升降（见 §7.3、§6.6）。面向玩家时也可表述为「店铺评价」。 | 好感值、口碑、口碑热度、店铺口碑、店铺整体口碑、店铺评价（作正式术语时）、评价 |
| **回头客** | 因好感度较高而重复到店的顾客。好感度越高，回头客越多（见 §6.6）。 | — |
| **热度** | **独立于好感度**的客流指标，取值 `0~100%`。顾客每完成一次购买 → 热度↑；举办活动（发传单、投放广告等）→ 热度↑。热度达 100% 触发**购物狂潮**（见 §7.6）。 | 人气（作正式术语时）、口碑热度 |
| **购物狂潮** | 热度达到 100% 触发的正向事件：短时间内大量增加到店客人（见 §7.6）。 | 购物热潮 |
| **回合** | 游戏时间的基本单位，一个「决策 → 营业 → 结算」周期。当前通常对应「一天」；后续如「夜市街」等地点可能只占一天中的**部分时段**，故统一以「回合」为准。 | 一天、一局、一天（作时间单位时）|
| **地点** | 摆摊阶段可选择的经营点位（如学校街、写字楼街、商业街）；面向玩家的叙事语境中可称「街道」。 | 地段、摆摊点、场景 |
| **商业街** | 最高阶地点（融合步行街 / 夜市的特征），也是**开店门槛地点**。 | 步行街、夜市（作正式地点名时）|
| **开店门槛** | 从摆摊进入开店的条件：商业街好感度 **≥ 60%** 且 资金达到开店最低要求（见 §4.2）。 | — |
| **冰箱 / 货仓** | 摆摊阶段的主料容器 = **冰箱**（占格博弈）；开店阶段的食材总仓 = **货仓**（单一容量池）。二者不可混用。 | 仓库（泛指时）、库存（作容器名时）|
| **出餐台** | 寿司**制作完成后暂存待摆的容器**，有序成品列表，有容量上限（初始 4，可升级）。成品先落出餐台（**备货阶段即时生产**、**营业阶段队列逐个制作**）；营业阶段出餐台满则制作暂停、出空位自动恢复，备货阶段满则无法再生产。出餐台上的成品**不参与售卖**，玩家须手动拖放到**货架**才能售出；也可拖到垃圾桶处理（备货阶段=取消退料返还食材，营业阶段=作废沉没成本）（见 §5.4）。 | 缓冲区、缓存区、暂存区（作正式术语时）|
| **食材保质期 / 成品新鲜度** | **食材（原料）**的过期时限称「保质期」；**已做好的寿司**在传送带上的转圈时限称「新鲜度」。二者是不同对象，不可都叫「保质期」。 | 用「保质期」指代成品新鲜度 |
| **作废** | 成品或食材因卖不掉 / 过期被清除。其经济后果 = **已投入的食材采购成本无法收回（沉没成本，实亏）**，而非清除动作本身额外扣钱 / 罚款。 | 倒掉、扔掉、丢弃（作正式动作名时）|
| **流失 vs 浪费** | 流失 = 顾客没买就走（机会成本，「少赚」，**不损失本钱**）；浪费 = 作废（食材采购成本沉没 = **实亏**，非额外罚款）。两者痛感不同，务必区分（见 §5.6）。 | — |
| **前排取货位** | 营业中站在餐车/货架前、当下正在「选货」的顾客位，数量有限（初始 2，升级至 3~5）。货架上有想要的即取走结账，没有则犹豫、超时流失（见 §5.5）。 | 取货台、窗口位、摊前位 |
| **等待队列** | 尚未进入前排取货位、排队等待的顾客序列，**无上限**。每人头顶显示具体想要的寿司图标，是玩家中期生产优先级的情报源；前排有人离位时队首补入（见 §5.5）。 | 排队区、候客区 |
| **确认情报 / 小道消息** | 好感度解锁的**可信情报** / **概率性传闻**（可能失真）。二者的呈现载体系统名为「流言系统」（见 §7.7）。 | 用「流言」指代确认情报 |
| **阶段 ①~⑤ ↔ 里程碑 M1~M5** | 设计侧用阶段编号 ①②③④⑤（见 §4）；开发侧用里程碑 M0~M5（见 `03-开发路线图.md`）。对应关系：①≈M1、②≈M2、③≈M3、④≈M4、⑤≈M5（M0 为项目骨架）。 | 混用两套编号而不说明 |
